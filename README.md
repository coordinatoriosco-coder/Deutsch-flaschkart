# German Flashcards Behzad

این پوشه برای GitHub Pages آماده شده است.

## فایل‌ها
- `index.html` فایل اصلی فلش‌کارت است.
- `.nojekyll` برای انتشار ساده به‌صورت سایت استاتیک است.

## انتشار با GitHub Pages
1. در GitHub یک Repository جدید بساز.
2. فایل‌های `index.html` و `.nojekyll` را در ریشه Repository آپلود کن.
3. در Repository به Settings > Pages برو.
4. انتشار را از Branch اصلی `main` و پوشه Root فعال کن.
5. لینک GitHub Pages را در Safari آیفون باز کن.
6. در Safari از Share > Add to Home Screen استفاده کن.

مهم: نام فایل اصلی باید `index.html` باشد.
